# 提示词优化系统提示词作用域收口记录

## 问题原因

此前 `system_prompts` 的管理页和运行时都按通用 `targetFeature` 处理：后台可以选择生图、生视频、脚本、提示词生成、分镜等功能，文本能力也会把对应配置拼入多个功能的 system prompt。这样“提示词优化系统提示词”存在被其他功能读取的风险，也不符合该配置的实际用途。

## 本次处理

- `system_prompts` 的唯一业务作用域固定为 `prompt_optimize`。
- 管理端列表只查询提示词优化记录；新增和编辑页面不再提供其他功能选项，表单中的功能固定显示“提示词优化”。
- 管理接口拒绝其他 `targetFeature`，编辑时额外限制数据库记录必须属于提示词优化，避免借用接口修改旧的其他功能记录。
- 运行时对非 `prompt_optimize` 目标 fail-closed，不调用数据库 loader；生图、生视频、脚本生成、提示词生成、分镜和工具不会读取这张表。
- 生图/生视频保留原有任务服务兼容调用，但该调用固定返回空 system prompt；其他文本功能保留各自内置指令。

## 用户可见入口

- `系统设置 → AI 文本能力 → 编辑提示词优化系统提示词`
- `AI 模型管理 → 功能页配置 → 提示词优化 → 编辑系统提示词`
- `内容合规 → 系统提示词`

进入“内容合规 → 系统提示词”后，页面会直接说明作用域，并通过“新增优化规则”维护注入提示词优化模型的自定义规则。

## 风险与边界

数据库中历史遗留的其他 `target_feature` 记录没有被删除，避免无必要的数据破坏；它们不会被管理列表展示，也不会被运行时读取。如需清理历史数据，应另行确认后做数据迁移。
