# 媒体上传与访问修复说明

日期：2026-06-14

## 本次修复解决什么

1. 后台上传图片/视频后，后台能看但小程序显示/播放 403。
2. 历史公开模板图、模板视频因为 COS 对象实际仍是私有读，公开 URL 访问失败。
3. 小程序上传默认超时太短，图片和视频更容易超时。
4. 小程序下载保存图片/视频时，没有把后端文件代理域名纳入可信下载来源。

## 本次改动

1. 服务端公开媒体返回优先走 `/api/v1/files/<fileNo>/content` 文件代理地址。
2. COS 上传 `visibility=public` 时，会同步写入对象 `public-read` ACL。
3. 后台切换文件公开/私有时，会同步更新底层对象权限，不再只改数据库。
4. 新增历史公开文件修复脚本：`npm run repair:public-files`。
5. 上传校验改为优先读取文件头，避免图片上传时整文件读入内存再校验。
6. 小程序默认请求超时调到 `60s`，上传图片调到 `120s`，上传视频调到 `300s`。
7. 小程序下载保存逻辑增加后端文件代理域名白名单支持。

## 上线后必做

1. 在服务器执行：

```bash
cd /www/wwwroot/ai-creator/current/server
npm run repair:public-files
```

2. 确认微信公众平台合法域名：

- `request`：`https://你的后端域名`
- `uploadFile`：`https://你的后端域名`
- `downloadFile`：`https://你的后端域名`
- `downloadFile`：对象存储/CDN 域名也建议保留

3. 确认 Nginx 上传与代理超时：

```nginx
client_max_body_size 200m;
proxy_connect_timeout 60s;
proxy_send_timeout 300s;
proxy_read_timeout 300s;
```

## 影响范围

- 服务端上传接口
- 服务端公开模板/公开媒体返回地址
- 后台文件可见性切换
- 小程序上传超时
- 小程序下载保存

不涉及：

- 数据库表结构变更
- 模板业务字段变更
- 后台页面结构变更

## 风险提示

1. 这次优先修的是腾讯 COS 公开读链路；如果未来切换到其他存储，需要确认对应适配器是否也支持 `setVisibility`。
2. 后台网页上传已在支持的对象存储上优先走浏览器直传；服务端中转链路仍保留为本地存储、未支持 provider 或直传失败时的兜底。
3. 如果线上 COS Bucket 自身有额外策略限制，仍需以腾讯云控制台策略为准。
