# 小程序性能与手机号登录优化（2026-08-29）

## 已完成

### 性能

- 灵感页接口改为服务端分页，默认每页 24 条、最大 50 条；页面触底时按需追加，不再一次拉取全部模板。
- 模板列表的收藏状态由逐条查询改为一次批量查询，避免已登录用户在长列表上产生 N+1 数据库查询。
- 生图、生视频页只请求当前创作模式的模板；切换到其他模式时再加载，并按模式缓存 60 秒。首次进入由原来的 3 个/4 个并发模板请求降为 1 个。
- `taskPoller` 新增取消订阅句柄；结果页、作品库与任务 store 在离页或任务结束后释放监听和轮询任务，避免后台持续 5 秒轮询。

### 手机号登录

- 微信登录响应现在包含脱敏 `phone` 与 `phoneBound`。该状态完全由服务端 `users.phone` 决定。
- 已绑定手机号的账号重新微信登录时，客户端直接写入会话并跳过 `getPhoneNumber` 授权弹窗。
- 手机号已调整为可选资料：已有 token 的受保护操作不再因手机号未绑定受阻。
- 新账号和服务端确认未绑定手机号的账号首次仍会收到可选授权提示。授权拒绝、未返回 code 或绑定失败时照常登录，并将“已提示”状态持久化；用户仍可在“我的”页手动绑定。

## 授权失败边界

微信小程序在用户拒绝授权或未返回 `detail.code` 时，不向客户端提供可信手机号；客户端不会保存虚假号码或把临时 `code` 当手机号。此时仅保存账号的 `phoneAuthorizationPrompted` 偏好，以避免后续自动弹窗。

偏好同步采用静默最佳努力策略：网络异常时，本次会话仍可使用并由本地缓存避免重复提示；如果换设备前服务端始终未同步成功，可能会再次出现一次提示。
