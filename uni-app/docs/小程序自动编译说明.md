# 小程序实时编译说明

最后核对：2026-08-29。实时编译使用仓库内的 `watch:mp-weixin` 脚本，不依赖已不存在的 `.bat` 文件或机器专属路径。

## 启动

在仓库根目录执行：

```bash
npm ci --prefix uni-app
npm run watch:mp-weixin --prefix uni-app
```

首次安装依赖需要等待。看到 `Starting mp-weixin watch build...` 后不要关闭该终端；停止时按 `Ctrl+C`。

## 微信开发者工具

导入实时编译输出目录：

```text
<仓库根目录>/uni-app/dist/build/mp-weixin
```

脚本运行期间，保存 `uni-app/src` 中的 `.vue`、`.ts`、`.scss` 等源文件会触发重新编译。微信开发者工具通常会自动刷新；未刷新时手动点击“编译”。

## 正式构建

生产构建前在 `uni-app/.env.production` 配置 HTTPS API 地址，再执行：

```bash
npm run build:mp-weixin --prefix uni-app
npm run check:mp-size --prefix uni-app
```

生产构建同样输出到 `uni-app/dist/build/mp-weixin`，可直接导入微信开发者工具上传。
