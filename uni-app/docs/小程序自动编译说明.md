# 小程序自动编译说明

## 怎么用

1. 双击项目根目录下的 `启动小程序自动编译.bat`。
2. 第一次运行如果没有依赖，脚本会自动执行 `npm install`，需要等几分钟。
3. 看到脚本开始执行 `npm run dev:mp-weixin` 后，不要关闭这个窗口。
4. 打开微信开发者工具，导入目录：

```text
I:\AI_creator_sum\uni-app\dist\dev\mp-weixin
```

## 是否会自动编译

会。脚本运行期间，修改并保存 `uni-app\src` 里的 `.vue`、`.ts`、`.scss` 等文件，会自动重新编译到：

```text
uni-app\dist\dev\mp-weixin
```

微信开发者工具导入这个目录后，一般会自动刷新；如果没刷新，点一次开发者工具里的“编译”。

## 什么时候用 build

日常开发和实时预览用这个脚本即可。正式打包时再运行：

```bash
npm run build:mp-weixin --prefix uni-app
```
