# 手机号可选登录（2026-08-29）

## 目标

手机号不再是登录或受保护操作的前置条件。首次登录仍展示一次微信手机号授权；用户拒绝、未获得授权 code 或绑定接口失败时，仍允许完成登录，并且之后不再自动请求手机号授权。

## 实现

- 服务端在 `user_profiles.preferences` 中增加默认值 `phoneAuthorizationPrompted: false`，无需数据库迁移。
- 用户拒绝/失败时，小程序先保存登录会话，再把 `phoneAuthorizationPrompted: true` 静默同步到服务端，同时写入本地会话缓存。
- 后续微信登录响应及完整用户资料会带回该偏好，首页仅在“未绑定手机号且从未提示过”时展示一次可选绑定弹窗。
- `ensureLoggedIn` 不再因手机号未绑定阻断功能；个人中心的“绑定手机号”入口保持可用，用户可随时补充绑定。
- 已真实绑定手机号的账号仍以服务端 `phoneBound` 为准，登录时直接跳过手机号弹窗。

## 边界与风险

- 拒绝授权时微信不会提供可信手机号，因此不会写入虚假号码；仅记录用户已被提示过。
- 同步偏好接口采用静默最佳努力策略：网络异常时本次会话仍允许使用并由本地缓存避免重复提示；若之后换设备且服务端同步仍未成功，可能再次收到一次提示。
- 未使用真实微信账号与 `getPhoneNumber` 线上接口联调；已完成静态回归、类型检查和小程序正式编译。
